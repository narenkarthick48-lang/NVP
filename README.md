
# NVP AI

### Your All-in-One AI Assistant

NVP AI is a multi-model AI assistant that brings different AI providers into one simple chat interface.

## Features

- ChatGPT-style interface
- Multiple AI models
- Automatic AI selection
- Chat history
- Mobile responsive design
- Secure API integration

## AI Providers

- Google Gemini
- NVIDIA NIM
- Groq
- OpenRouter
- DeepSeek
- Mistral

## Technologies

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Vercel
